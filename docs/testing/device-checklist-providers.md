# Device checklist: providers as plugins

The design is docs/superpowers/specs/2026-10-18-provider-plugins-design.md, built in six milestones. Each section is checked on an iPhone, in annai installed to the Home Screen, at the address you travel with. Your own servers (your llama.cpp server, your maiGo router) are named here, never addressed.

## Milestone 1: providers and abilities

Before you update, have at least one endpoint set up the old way (Sign in with OpenRouter, or a key), so the moving over can be seen.

- [ ] **The moving-over card.** After the update, at annai's next start: a card "Settings → Models changed" names your old endpoints and says their keys were removed. **Open Models**: no providers, and the roles hold only the phone's dictation and the browser voice. Restart annai: the card doesn't come again.
- [ ] **Sign in with OpenRouter** (paste the code): Models → Sign in with OpenRouter opens OpenRouter in Safari; sign in, copy the code, come back, paste it, **Connect**. A card "Signed in with OpenRouter". Models lists **one** provider, OpenRouter, with "Chat, Transcription, Voice". Main has Gemma 4 31B (free); speech in ends with OpenRouter's Whisper, after phone dictation; speech out has the browser voice first, then Fish Audio's free voice.
- [ ] **Add OpenAI and Test it.** Models → Add a provider → **OpenAI** → **Add**: no question, its page opens. Settings → Plugins lists OpenAI, OpenAI Responses and OpenAI-compatible speech. On OpenAI's page, give your key, **Save**: the key field says "saved", and the key is never shown again. Its abilities: Chat (Responses), Chat (Chat Completions) switched off, Transcription, Voice. In Chat (Responses), **Test** the first model: "Everything works." In Voice, open a voice, **Play a sample**.
- [ ] **One key:** Settings → Copy diagnostics, paste it into a note, search for your OpenAI key: it isn't there.
- [ ] **Airplane mode:** an added provider still works without annai's site. Turn on Airplane mode, then Wi-Fi only (or any network where annai.guide isn't needed): talk to Shiori. She answers through OpenRouter or OpenAI. Trace → Kind **Web** shows no download of a plugin; with no network at all, her turn fails in words, and nothing asks to install anything.
- [ ] **Remove a provider:** OpenAI's page → **Remove provider**: the line above it says it removes its key, its models and their places in roles, and the OpenAI plugin. Tap twice. Models no longer lists it, its models are gone from the roles, and Settings → Plugins no longer lists OpenAI or OpenAI Responses; Chat Completions and OpenAI-compatible speech stay, as OpenRouter needs them.

## Milestone 2: servers you run

Your llama.cpp server here is the Unsloth Studio one, with HTTPS in front of it on your tailnet, and a key from Studio's Settings → API. Before you start, open Settings → Updates: if it offers Chat Completions 0.5.0 or Custom provider 1.1.0, update them.

- [ ] **The local servers are offered.** Models → Add a provider lists llama.cpp, LM Studio, Ollama, SGLang and vLLM.
- [ ] **Add llama.cpp.** Choose llama.cpp → **Add**: no question, its page opens. The address says `http://localhost:9931/v1`, and the note says a phone needs an HTTPS address. Type your server's plain `http://` address on your home network and **Save**: it's refused, saying a server on another computer needs HTTPS in front of it. Then give its HTTPS address (ending in `/v1`) and its key, **Save**: the key field says "saved".
- [ ] **Fetch model list.** In Chat, **Fetch model list**: your server's models. **Add** the one Studio has loaded. On its page, the context window is what Studio holds (correct it if not), and tick **Takes photos** if the model reads images: Studio's list doesn't say.
- [ ] **Test.** On llama.cpp's page, **Test**: "Everything works.", with "✓ Tool calls work." and "✓ Photos work: it saw the red square."
- [ ] **Try this model streams.** On the model's page, ask "Plan a morning in Big Sur": the words appear as they're written, with **Stop** showing until it ends, then its tokens.
- [ ] **She thinks, and shows it.** Put the model in Main, and **Test** it again: "✓ It also answers at Main's level (medium)." Talk to Shiori: her thinking shows while she works, then her answer. Ask something that needs a tool ("what's the weather at Bixby Bridge?"): she calls it. Trace → Type contains `model.turn`: the turn has her reasoning, and tokens in and out.
- [ ] **The quick decision doesn't think.** Put the model in Quick decision too, and turn voice on. Say something to someone beside you, not to Shiori. Trace → Type contains `model.turn`: a `decide` turn at level off, with no reasoning in its reply, answered in a second or two.
- [ ] **maiGo through Custom provider.** Add a provider → **Custom provider** → **Add**. Name it maiGo, give its HTTPS address (ending in `/v1`) and its key, **Save**. Use Chat Completions, and add a model it routes by id. **Test**: "Everything works." On the model's page, **Try this model**: the answer comes in one piece. Ask for something long ("the history of Big Sur in 600 words"): if it stops with "No output started in time.", raise Main's "Wait for the first words" in Models (and Settings → Voice → Wait for her first words), as Custom provider's note says, and ask again.

## Milestone 3: one catalog

- [ ] **Models → Add a provider opens the catalog on model providers.** The Model providers chip is on and only that kind shows, with Custom provider last. Each row has its abilities, Free where it has free models, and "Official · Data only ·" its size.
- [ ] **Search "unsloth".** llama.cpp alone, saying "Also for: Unsloth". The keyboard stays up while you type, and the box keeps what you typed.
- [ ] **Search "lm studio", then "lmstudio".** Both list LM Studio first, then llama.cpp, saying "Also for: LM Studio".
- [ ] **Search "free voice"**, with the Model providers chip off: OpenRouter, and not OpenAI.
- [ ] **Add from the catalog.** Search "ollama", then **Add**: Ollama's page opens. Back at Models → Add a provider, Ollama says "Added", with **Add another**.
- [ ] **A speech role's Add.** Models → Speech in → **Add a provider**: the Transcription chip is on; OpenAI, Groq, OpenRouter and Local speech server are there, Anthropic isn't. Speech out's opens on Voice; OpenAI is there, Groq isn't.
- [ ] **Plugins → Add opens on everything,** grouped: Model providers, Voices and transcription, Backup places, Tools and MCP, Developer. Tap **Backup places**, then **Set up** on S3-compatible storage: Backups opens with it chosen. Back on Add, **Set up** An MCP server: MCP servers opens.
- [ ] **Installing from an address** is at the foot of the Add screen: an address, **Get it**, and the install screen comes first. Cancel.
- [ ] **Plugins search.** Settings → Plugins is grouped by kind, provider plugins under Model providers naming your providers. Type "responses": OpenAI Responses first, then OpenAI, whose description names the Responses API. The chips filter as on Add.
- [ ] **Offline.** In Airplane mode, Models → Add a provider says annai's catalog couldn't be loaded, and what is installed still lists. **Add another** on a provider you have works.

## Milestone 4: OpenRouter as a code provider

Before you start, open Settings → Updates: if it offers OpenRouter 2.0.0, Chat Completions 0.7.0, Custom provider 1.2.0, or llama.cpp, Ollama or LM Studio 1.1.0, update them.

- [ ] **After Erase, the welcome names the sign-in.** Settings → Erase. At the welcome's last step (Get started) in the Home Screen app: "Connect a model, so Shiori can think. Sign in with OpenRouter is the quickest way, and it starts you on free models." Tap **Set up a model**.
- [ ] **Models' first tap opens OpenRouter.** Models shows "The quickest start" with **Sign in with OpenRouter**; for a moment, on a slow connection, a greyed "Getting the sign-in ready…" may show first, but never a link that does nothing. Tap **Sign in with OpenRouter** once: OpenRouter opens in Safari at once. Sign in, copy the code, come back to annai: the paste box is there (also if iOS closed annai meanwhile). Paste it, **Connect**: a card "Signed in with OpenRouter", and Models lists **one** provider, OpenRouter, with "Chat, Transcription, Voice". The quickest start is gone.
- [ ] **Sign in again.** Open OpenRouter's page: in the key's place, "Sign in again for a new key, in place of the one saved." with **Sign in again**, and the key field below it. Tap it, sign in, paste the new code, **Connect**: "annai keeps the new key for OpenRouter's chat, transcription and voices." Models still lists one provider. In your OpenRouter keys (openrouter.ai/settings/keys), the new key is labelled annai; delete the old one there.
- [ ] **Its plugin has code.** Settings → Plugins → OpenRouter: "A model provider · has code · version 2.0.0", with the full-access note. Add → search "openrouter": its row says "Official · Has code".
- [ ] **Another provider tidies the start away.** Remove OpenRouter (its page → Remove provider, twice). Models shows the quickest start again. Then Add a provider → **Ollama** (or any other) → **Add**: in Settings → Plugins, OpenRouter's plugin is gone, as no provider comes from it.
- [ ] **Your llama.cpp server's context window.** Add llama.cpp with your Unsloth Studio server's HTTPS address and key (as in milestone 2), **Fetch model list**, and **Add** the model Studio has loaded: its row says "262K context" (or what Studio serves), and on its page **Takes photos** is ticked, as Studio's /props says the model reads images.

## Milestone 5: "Custom provider" looks for itself

Before you start, open Settings → Updates: if it offers Custom provider 2.0.0, update it. A provider you added from Custom provider before keeps working as it is: the look is for adding.

- [ ] **maiGo: what it offers, at no cost.** Models → Add a provider → **Custom provider** → **Add**: a screen titled Custom provider, with Address, API key (optional) and **Look for what it offers**, and **Add by hand** below. Give your maiGo router's HTTPS address (ending in `/v1`) and its key, and tap **Look for what it offers**. Under "Found, at no cost": ✓ Model list: its number of models, ✓ Chat Completions, ✓ OpenAI Responses, ✗ Anthropic Messages: not found, ✗ Transcription: not found, ✗ Voice: not found. Under them: "annai only asked for the model list and sent an empty request to each known path. Nothing here costs money; Test sends real requests."
- [ ] **Nothing was charged, and the key stayed put.** maiGo's own log shows a model list and empty requests (no model; the chat ones with a limit of one token) refused (400, "missing required field: model"), and no completion. In annai, Trace → Kind **Web**: one request per path, each with its status, from plugin:provider-another-address. Settings → Copy diagnostics, paste it into a note, search for maiGo's key: it isn't there.
- [ ] **Without the key.** Clear the key field: what was found goes. **Look** again: Chat Completions and OpenAI Responses are either ✓ with "it asks for a key", or ? "it asks for a key before it says what it has: give the key, then look again". Nothing maiGo doesn't have is ✓, and there's no Add with these without a ✓.
- [ ] **Add with these, then Test.** Give the key, **Look**, **Add with these**: maiGo's page opens, named by its host, with Chat Completions and OpenAI Responses switched on and the others off; the line by Remove names Chat Completions and OpenAI Responses as what it would take with it. Name it maiGo. In Chat Completions, **Fetch model list**, add a model it routes, and **Test**: "Everything works." Only now does maiGo's log show a completion.
- [ ] **Your llama.cpp server: what it offers.** Add a provider → **Custom provider** → **Add**. Give your Unsloth Studio server's HTTPS address *without* `/v1`, and its key, and **Look**: annai looks at `/v1` too, and says "What https://…/v1 offers:". Measured from this machine on 2026-10-19, Studio answered: ✓ Model list (its models), ✓ Chat Completions, ✓ OpenAI Responses, ✓ Anthropic Messages, and "✓ Transcription: the path is there; Test says whether a model there can listen" and the same for Voice (Studio has those paths). Unless Studio's list names a Whisper or TTS model, those two say they're added switched off. **Add with these**: Anthropic Messages' own address is the server's address without `/v1`, and Transcription and Voice are off on its page unless the list named such a model. Remove it afterwards if you like: llama.cpp's own plugin knows the server better (its context window, its thinking switch).
- [ ] **Changing your mind.** After a look, change one letter of the address: what was found goes, and it says "The address changed: look again." Tap **← Add**, then Settings → Plugins: Custom provider isn't listed (unless a provider comes from it already).
- [ ] **A site that isn't for web apps.** Give `https://example.com` and **Look**: each line says "blocked: it doesn't allow web apps (no CORS)", the words above say the same, and there's no Add with these.
- [ ] **Not reachable, and plain http.** Turn on Airplane mode and **Look** at maiGo: "annai couldn't reach …. Check the address and your connection." Turn it off. Give your llama.cpp server's plain `http://` home-network address: refused before anything is sent, saying a server on another computer needs HTTPS in front of it.
- [ ] **OpenRouter's Add.** Add a provider → **OpenRouter** → **Add**: its own screen, with **Sign in with OpenRouter** (a link that already has its address) and **Add by hand** below. **Add by hand** opens OpenRouter's page with the key field. Remove it afterwards if you don't want it.

## Milestone 6: conflicts made explicit

The test plugins are served by annai's stand-in on the machine that serves annai, as in the milestone 8 checklist, on a free port (never 8765, 8790–8799 or 18010–18014), for example:

    node scripts/mcp-stand-in.mjs --port 8486 --token <a long random token> --files test/fixtures/extensions
    tailscale serve --bg --https=8487 http://127.0.0.1:8486

Below, `<stand-in>` is `https://<machine>.<tailnet>.ts.net:8487`.

- [ ] **What was in use stays in use.** If a plugin replaced how Shiori looks, her dock or the Now card before the update, it still does after it, and its page (Settings → Plugins → its name) says, under Names, "How Shiori looks: this one is used (your choice)." with **Undo**.
- [ ] **A taken tool name.** Settings → Plugins → Add → Address of a plugin or skill: `<stand-in>/files/clash-tool/annai-plugin.json` → **Get it** → **Install**. Open Clash tool's page: under Names, "Not used: the tool weather is already provided by Places tools." Ask Shiori "What's the weather at Bixby Bridge?": Trace → Tools shows `weather` with Places' forecast.
- [ ] **Switch, and Shiori uses it.** On Clash tool's page, **Use this one instead**: "The tool weather: this one is used (your choice)." Settings → Plugins → Places tools: "The tool weather: the one from Clash tool (clash-tool) is used (your choice)." Ask again: the answer is "Clash weather: always sunny." (Trace → Tools).
- [ ] **Undo, on the other page.** On Places tools' page, **Undo**: its Names section goes. Ask again: Places' forecast. Remove Clash tool.
- [ ] **A plugin that replaces how Shiori looks.** Zip `test/fixtures/extensions/avatar-replaces/` on the machine, AirDrop or save it to Files, then Settings → Plugins → Add → Install from a file. The install screen: under What it replaces, "It replaces how Shiori looks from annai.", with **Install and use it** and **Install, keep annai's**. Tap **Install and use it**: the dock shows a mountain in Shiori's place.
- [ ] **Undo it.** Mountain look's page: **Undo**: Shiori comes back in the dock, and the page says "Not used: how Shiori looks is already provided by annai.", with **Use this one instead**. Tap it: the mountain again. Turn the plugin off: Shiori; on: the mountain. Remove it.
- [ ] **A package from another place.** Install Clash tool from its address again, and on its page tap **Use this one instead**. Then pick the same folder zipped, from a file: the install screen says, as a warning, that version 1.0.0 is installed from `<machine>…/files/clash-tool/annai-plugin.json`, not where this one comes from, and that kept, its settings, keys and your choices for its names go to this one. Tap **Install fresh**: Clash tool's page says Not used again. Remove Clash tool.
