# Lessons

What this project's changes taught us. Read it all before changing an API, a format or an agreed
behaviour. A line's full story is the entry of the same date and name in `lessons-full.md`;
a merged line names each of its entries.

When one changes, add the full entry to `lessons-full.md` and its line here, newest last, in the same
commit. Never merge lines to save space; before this file passes 80 KB (what one Claude Code read returns, measured
2026-11-15), ask the user (the user's pick of 2026-11-15, "Yes, 80 KB for both (Recommended)", for annai's and housekeepd's caps, replacing the 24 KB of 2026-11-12).
