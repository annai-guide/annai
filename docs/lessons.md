# Lessons

What this project's past changes taught us. Read all of this before changing an API, a format or an
agreed behaviour here. For the full story of a line, find the entry with the same date and name in
`lessons-full.md`.

When one has to change, add the full entry to `lessons-full.md` and one line here, newest last, in the
same commit as the change. Keep this file under 20 KB: at the cap, merge lines before adding.

- **2026-10-23 annai's translation TSV: a note part for the translator**: when a file is written by a tool and by people, give each writer a part the other never touches.
- **2026-10-26 annai: modules pass data, and words are made at display**: pass data between modules (kinds, flags, values, ids), and make whole sentences only where they are shown. Never match on words a person reads.
- **2026-10-27 annai: plain fields are English, `shown` holds the screen's words**: when one value has two audiences, make the field the machine or model reads the default, and the human-facing one the optional extra. A forgotten extra then shows up as English on screen, where people notice it, instead of leaking.
- **2026-10-27 annai: a new record always writes the field that tells it from an old one**: when later code must tell old records from new ones, write the field on every new record, with `null` for empty, and test for the key (`'said' in h`), not its value.
- **2026-10-27 annai: an error's optional parts go in one options object from the start**: after the required arguments, anything optional goes in one options object, even when there is only one so far. A new optional part then changes no caller.
- **2026-10-27 annai: a choice keeps its value and its words apart**: give a choice two parts from the start, the value the code keeps and the words a person reads, even while they are the same.
- **2026-10-27 annai: an error carries which of its words are a developer's English**: when the language of a value matters to whoever shows it, the value carries that fact (a flag, or the part that differs), set where it is made. A comment in the source reaches no reader.
- **2026-10-27 annai: a plugin's `api` is the oldest host it needs, not an exact match**: a version a component declares about its host is the minimum it needs. The host accepts anything at or below its own, and the number is raised only when the component starts using something an older host lacks.
- **2026-10-27 annai: a name the screens show is read from what is stored, not from what happens to be running**: read what a screen shows from the stored source of truth, even if that makes the call async. A cache or a network copy is only for when nothing is stored.
- **2026-10-28 annai: an official plugin's translations are not files of its package**: when a unit you version and verify whole carries parts each user needs only one of, or parts that change on their own schedule, give those parts their own hash and fetch path from the first version, keyed by what selects them.
- **2026-10-28 annai: what a model makes of a stored file is kept beside it, and an explicit ask redoes it**: keep derived content that later requests need with its owner, named by what it was made from (a content hash), and let an explicit ask redo it, newest wins.
- **2026-10-29 annai: mark both ends of a move on their records**: when one operation spans two records, write the relation on both, so either side can reverse the whole thing. Mark what an undo itself writes, so later decisions never mistake it for the user's own work.
- **2026-10-29 annai: keep a reading's uncertainty per field, where the user acts on it**: record a model's uncertainty at the level the user acts on (here the field), not as one flag over the whole record. Require the field on every new write, so a record without it can only be an old one.
- **2026-10-30 annai: a provider's reply is kept as it came, beside annai's reading of it**: when a provider checks what is sent back, keep its reply exactly as it came, beside annai's own reading of it, and make the requests of one exchange append-only; annai's parts are for annai and for other models.
- **2026-10-30 annai: a native reply goes to the models that can read it, and a refusal is read by status**: scope what a provider returns to who can read it, not to where it was fetched; act on a request's status and on what was sent, not on an error's text.
- **2026-11-01 annai: a log's last number never goes back**: when anything compares a position in a log, removing entries must still move the position forward; give removal its own entry rather than rewinding.
- **2026-11-02 annai: live Koe gets `sleep` back (plan decision 29 reversed)**: an end condition built on the absence of a signal (silence, no fixes, no events) needs a second way out that doesn't wait for that absence: a decision by whoever can judge, or an explicit command.
- **2026-11-04 annai: a "moved" watch counts from when it was set, not from Shiori's last wake**: a watch or timer counts from its own start, and resets only on its own firing. Don't reset it from an unrelated event because that event seems to make it redundant: how often that event happens will change.
- **2026-11-05 annai: screen-on is one setting, and a tap in Auto holds voice for that exchange**: a direct action outranks an automatic mode. An automatic setting decides what happens when the user does nothing, never what their tap means.
- **2026-11-05 annai: all a reload needs is one overwritten record**: state a restart needs is one record written from one method, with values that must agree written together. A log is evidence, not state. A count that must survive is kept as a counter, and each consumer records its own reading of it. Anything that wipes state stops its writers first.
- **2026-11-05 annai: voice, four changes from the second drive**: a threshold learned from outside sound never takes one sample as truth. Never let a wait depend on an event the other side may not send: bound it, and say what a late one means. Recording and sending are separate steps. "It worked once" isn't a state: sound can get stuck later, so keep the way back armed. And test a real tool call before shipping a model: a clean open proves nothing (Gemini 3.8 Live Extended Thinking opened, and never made a call).
- **2026-11-05 annai: a gate reads the conversation, not one line**: give a classifier the context a person would need. And give it a way to be wrong cheaply: here a wrong "for her" costs a short reply, while a wrong "not for her" loses what the user said.
- **2026-11-05 annai: Auto voice removed; voice and Live are each one tap**: an automatic setting must rest on a signal seen working on the real device, and be sayable in one sentence. Keep one measured rule (driving, from GPS) and make the rest a switch the user owns. A change of state is an event told once from its source, not worked out again from a value that can change for other reasons.
- **2026-11-05 annai: a model its plugin dropped leaves Koe's Realtime list at the update**: removing something from a catalog isn't finished until you've read what saved settings do with it. List what names it, then decide each one's fate, and test through the update path, not only on fresh data. When two saves must go together and the store has a transaction, use it: there's then no order to get right. A rule that reacts to an update goes out a release ahead of it.
- **2026-11-05 annai: one path for a gap in GPS evidence**: one question, one place that answers it. When fixes keep finding another disagreement between two places, take one away instead of syncing them. Cases that look different often decide the same way and differ in a few things you can name. A straight-line way can prove a drive went on, never that it ended.
- **2026-11-06 annai: a hold's date is in the drive record, and goes with its hold**: state that lasts past one event belongs in the record a restart reads from the start. A saved value that something can cancel is written when it is cancelled, not only when it is set: a copy that outlives what it belongs to is worse than none.
- **2026-11-06 annai: what only tests call is unused**: a member kept for tests is shipped code that no operator runs. Tests go through the real path, or keep their helper to themselves. A test seam stays only when it resets module state or is an option whose shipped default has its own test; an option only a test passes (`maxPackageBytes`) left the shipped limit untested.
- **2026-11-06 annai: a take-over belongs to the shell, not to the screen it leaves**: what must happen wherever the user is lives in the one place that is always there. A screen's listener only works while that screen shows, and says nothing about the others.
- **2026-11-06 Trip dates and last talked on the scope record**: a record that lists things carries what deciding among them needs, not only what today's list shows. A mirror has one writer per field and a key that says it was filled, so filling old records is one pass that ends. What can be read again from the source doesn't travel: an archive's copy could only be stale, or claim something.
- **2026-11-06 annai: looking isn't doing**: what the app acts on follows what the user did, not what's on screen. An open screen says where they're looking, and looking changes nothing that fires, reminds or takes over.
- **2026-11-06 annai: a copy is held to its source, and to what stands still**: a copy that outlives what it was made from carries a digest of what it was made from, and each look compares that with the source itself, whatever screen is open. Make the digest from data alone: a sentence, a language, a clock or a position would call off a good copy. And a read that failed is "could not look", never "nothing there" and never a part result: a read answers or nothing changes, so nothing downstream has to know how much was read, and what failed tries again by itself.
- **2026-11-06 annai: the conversation has its own address**: an address names the thing it shows, not "the current one". A screen opens what it shows only when the user moved there, never on a redraw. An old address goes where it now means by the shell's own replace, so Back can't land on it and bounce.
- **2026-11-06 annai: a tapped notification tells the open page which conversation**: when a page and its service worker ship apart, each message type does one job and carries what its receiver needs to act. The payload is outside text: the sender checks it by a strict rule, and the receiver uses it only as an address, which names nothing that isn't there and goes to the safe default.
- **2026-11-07 annai: Back and Forward skip what is gone**: an entry that can't be shown is passed over in the direction the user was going, once, in the shell before anything draws, for every address that names the thing; a move that passes entries also passes those at the address it left. That needs the history's order, so each entry carries its number beside its key (entries other code pushes too, with a number between), and a replace keeps it (`location.replace` drops `history.state`). Leaving a screen for good (Remove trip) goes the way Back goes, never forward to a new entry.
- **2026-11-06 A chat is a trip with a draft flag**: a thing made ahead of need carries its own mark, written by what makes it and cleared by what spends it, and every list, export and automatic follower leaves it out. An older reader that doesn't know the mark shows it as an ordinary record.
- **2026-11-06 start_trip refuses in an undated conversation**: when a thing becomes another by gaining a field, the tool that makes the other kind refuses where that field is missing and names the field and file to set. A change the model made for the user shows where they look, with Undo, read from the record that keeps the version before.
- **2026-11-09 annai: an archive's times stay within a date's range**: a number that is read as a date has a date's range in the format's schema (±8.64e15 ms), and a file outside it is refused as damaged when it comes in, not guarded in each screen that draws it.
- **2026-11-09 annai: a file's moves are undone as one chain, and Undo's count is her writes alone**: reverse a sequence of operations on one thing as one sequence, read in order from the records both ends keep, never step by step from guesses about the present. A count in a record counts one kind of thing, whichever side writes it, and what another field already says isn't counted again.
- **2026-11-09 annai: twoStep's optional parts in one options object**: the 2026-10-27 rule holds for any function other modules call, UI helpers too, not only errors: after the required arguments, anything optional goes in one options object, even when there is only one so far.
- **2026-11-09 Reading another trip is granted by annai, not by her**: an approval comes only from what the app drew and checks itself (its own card's option, or a heard line its strict word list matches, judged on what the user said last), never from text a model, tool or file can write, or from a plugin's message (a code plugin is trusted as annai's own parts are, docs/plugins.md, so a grant it writes to the log counts). A late tap is an ordinary line, and a tap answers the card by an id annai minted for it, never a provider's; a grant lives where it applies (the conversation's log), and one an import brought is no approval; what came from outside is marked as it comes in, so a standing "always" never reaches it.
- **2026-11-10 annai: a provider's rule for the sequence it is sent is enforced where the request is built, over whatever is stored**: when a provider defers a call it makes itself (Anthropic's web search beside a client tool), the rule for what may follow is part of its contract; keep it in the one place that builds the request, working from the stored history, so a fix reaches conversations already stuck and no stored format changes. Ask the real API for every shape (end of the history, middle, something other than the answering reply after it), and give the stand-in the same refusals.
