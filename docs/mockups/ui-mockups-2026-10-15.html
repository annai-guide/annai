Where plugins change the UI

The screens are built from named slots and components, and our own screens register through the same registry plugins use. A plugin can add to a slot, replace a named piece, or restyle everything.

  • SlotsPlaces a plugin can add to: status chips, Now card sections, dock actions, trip tabs, settings pages.
  • Card typesA renderer for a kind of card, often paired with a schema, like a ferry ticket or a tide table.
  • Named componentsEvery piece has a name: avatar, now-card, dock, plan-row. A plugin can replace one, for example different avatar art or a map-first Now card.
  • Whole screensA plugin can add a tab, or offer itself as the home screen for a mode such as hiking.
  • ThemesAll colors, type and spacing are CSS variables. A theme plugin changes the variables, so every screen follows, including other plugins' cards.
  • Stable vs. anythingPlugins run with full access, so they could rewrite the page directly. Slots, components and variables are the parts that keep working across updates.
